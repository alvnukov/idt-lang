# Original count fixture

`pm_umbrella_prepcert_counts_pc001.csv` is an unmodified 273-byte member of
*Raw counts from prepare-and-measure experiments implemented on quantum
processors*, Gabor Drotos and Abdelmalek Taoutioui (2024).
[Versioned original dataset](https://doi.org/10.5281/zenodo.10723401);
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The dataset authors do not endorse this analysis. Only this member is
redistributed. The SHA-256 is
`6e81009b2df68c0b10cbc41dc46e3fdf8b2ccd4850250b0cc15386d7040b7060`.

Each row is an aggregated count for one preparation, one binary measurement
and one output. This file is not a time-ordered list of trials and does
not contain setting-assignment probabilities. See the
[original paper, Appendix C](https://doi.org/10.1088/1367-2630/ad4e5c)
and the conditional interpretation in `scripts/NOISY_BINARY_CUTS.md`.
