# Which motions survive when the contact program is removed?

Give the same three-label law (`aa ↔ bb`, `Ta ↔ aT`) a fixed graph, but no list of edges to visit. Instead enumerate all possible single contacts that actually change the state. This defines possible histories, not their probabilities. Several useful questions can now be answered without enumerating every history.

## A two-state clock, and what can read it

Place one T in an odd cycle; alternate a,b on the remaining path. Exactly one edge can fire. It moves T across an adjacent a, and the very same edge is the only one that can fire next. There is one such two-state component per edge. It ticks in **changing events**, not seconds: attempts on disabled edges need not advance it. The two snapshots are related by reflection of the anonymous cycle. A test based only on one unlabeled snapshot cannot tell which phase it sees.

The [single-tag ring census](probe_undriven_ternary_ring.py) checks all 45,052 configurations from lengths 3 to 12, including 125,949 undirected transitions. It finds the predicted 125 components, with 35 two-state components on odd rings and none on the even rings in the range. An odd cycle is not necessary: a boundary between two alternating half-lines also supports the local oscillation. Two prepared clocks on a 5- and a 7-cycle with an inert connecting edge have four accessible combined states. Their distances to the bridge distinguish these states without coordinate labels, but the bridge transmits **no signal**. Those distances are an external graph diagnostic, not an internal observer or a synchronization mechanism.

## A distance constraint without a repulsion rule

Between successive T marks on a ring, count b sites with alternating signs, starting just after one mark. Call the signed result H. An ordinary contact preserves it. A tag can cross only an a: dropping or prepending a leading a reverses H; adding or removing a trailing a leaves it alone. Thus the cyclic list of magnitudes |H| persists, even though the marks themselves need no identities. A nonzero gap magnitude requires at least 2|H|−1 intervening sites.

Two otherwise similar eight-site preparations give a sharp check. Both have T at sites 0 and 4, two b sites and the same global staggered charge. From `TbabTaaa`, 48 of 100 accessible states have adjacent tags, the first three changing contacts away. From `TbaaTbaa`, none of 92 do: **both** gaps must retain an ordinary site. This is a conditional constraint from a stored pattern, not a force, a spin assignment or the Pauli principle.

The [gap checker](probe_ternary_gap_memory.py) replaces the ordinary word in each gap by its alternating count. At fixed tag positions, complementing alternate ordinary bits converts the allowed ordinary contact into an adjacent swap, so all arrangements with the same transformed count communicate. The reduced states and their allowed tag hops give exactly the same connected components in all 24 censuses (rings 4–11 with one to three tags): 133,096 raw states, 13,640 reduced states, 936 components. They do **not** generally give the same one-step transition probabilities. Already in one reduced state two preparations offer probability 1/8 versus zero of the same reduced transition under uniform edge offers.

## Exact, cheap reachability on an open path

The [open-path checker](probe_ternary_path_normal_form.py) needs just a pass over each input word. A pair aa is interchangeable with bb and can be shifted past any letter by native contacts: for instance, baa → bbb → aab. Park such pairs at one end. Between the remaining b letters, a can pass T and two a's can be parked. The resulting skeleton contains none of aa, bb or Ta. Two strings of equal length on the same labeled open path (endpoint contents may change) communicate **if and only if** their skeletons agree. A separate, potentially slower routine returns the actual sequence of contacts. There are 2^(n+1)−1 components for n sites; this is a combinatorial argument with executable controls, not a Lean theorem.

An independent exhaustive loop reproduces every component and the full attainable position set of each T rank up to length 10 (88,573 states including the empty string). At length 13 two fixed membership queries read 26 input symbols each; direct search tried 28,920 and 77,712 edge offers respectively. These are operation counts, not a timing ratio. A witness need not be cheap to execute: moving a block of m tags across a block of m a's requires exactly m² adjacent changes in this example. The same checker must **not** be reused unchanged on a ring: allowing a contact across the endpoints changes the equivalence relation. Compare the established use of irreducible strings in [Caha and Nagaj's pair-flip model](https://arxiv.org/abs/1805.07168); the extra commuting tag and the actual rule must be checked here.

## A contrast on a different primitive

The [staggered Rule 54 probe](probe_binary_rest_packets.py) retains its alternating clock. For a finite nonempty change on the empty infinite line, the leftmost occupied bit, once passive, advances left indefinitely. Before then it can advance right each step; a stationary transition puts it in the passive phase. An exact return of the **whole** finite pattern up to translation, including next phase, thus requires speed +1 or −1. This is not an argument about the centroid of a pair, or a probe on a populated medium.

On prepared periodic backgrounds the same initial two-bit change returns with speeds 1/2 or 1/3. Both the perturbed trajectory and the underlying periodic state must recur with the same translation and next matching. All 48 half-speed hits in the stated 1,024-launch periodic census have zero change in both soliton counts; none of the 1,024 launches returns with zero displacement within 12 half-steps. No exclusion for all media or longer return times follows. Soliton slowdown in this automaton is known ([Klobas et al.](https://arxiv.org/abs/1807.05000)); a difference between two prepared words is not automatically a massive particle. The contrast is useful because it distinguishes a supplied driving clock from the two-state undriven trap above.
